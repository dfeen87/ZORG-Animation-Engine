# Future direction — outside Build 0

ZORG names reusable animation technology. Commander-ZORG names the original
fictional universe, characters and productions motivating this experiment.
The software license does not automatically grant rights to creative artwork,
scripts, characters or third-party assets.

Potential later experiments include stable attached features and character
continuity; authored timing and scene orchestration; causally qualified motion
history; scripted palettes; and controlled camera studies. Each requires a
separate contract, independent evidence and explicit scope before code.

A creative authoring application and optional community platform are exploratory
directions, not launch commitments. Build 0 contains no placeholder subsystems,
website, social network, agent framework, database or cloud renderer. AILEE,
Phase-Memory Operator, AeroCam, SPECS and UFO remain unmodified and unintegrated.

The smallest next step is creator review of the full monochrome sequence, then
at most a documented geometry/force tuning take preserving this baseline.
If thin accents or recognizable features prove difficult, compare an attached
feature representation or circles/capsules before adding memory or governance.
